## Install

1. Click **Download for Windows** above.
2. Unzip `MediaConverter_Setup.zip` anywhere (for example your Desktop).
3. Open the folder and run **Media Converter.exe**. Keep `ffmpeg.exe` in the same folder.

Nothing else to install - everything is included. If Windows SmartScreen says "unrecognized publisher", click **More info &rarr; Run anyway** (the app isn't code-signed).

## What it does

- **From a link** - YouTube, Instagram, Facebook, TikTok, SoundCloud and 1,700+ other sites. Video (MP4, MKV, WEBM, MOV, AVI, GIF, up to 4K) or audio (MP3, M4A, WAV, FLAC, OGG, OPUS). Turn on **Download only a part** to grab just a section.
- **Convert a file** - drag in a file and pick the format: MP4 to MP3, MP3 to MP4 with a cover picture, and more.
- **Player & trim** - play a video or song, mark the start and end, preview it and save just that part.

## Updates

The app updates itself: a banner appears when there is a new version - click **Install and restart**. The download engine also updates on its own whenever sites change.

Use it only for content you own or have permission to download.
